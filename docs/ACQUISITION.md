# 查询采集与触摸屏控制

0.3.3按用户“只操作开发板，不碰仪表按键”的目标移除Auto Fetch模式。旧手册确实描述主动发送，但每个远程命令都会终止它，恢复需按仪表RMT，不适合作为本产品交互。旧版本记录仅在PROGRESS保留。

0.4.0 的模式切换、参数保护与通信记录见 [模式说明](MODES.md)。

## 正常流程

1. 未识别仪表时显示独立连接页，展示USB枚举、串口初始化、身份查询或具体错误；没有主读数与参数控制。
2. CP210x就绪后查询*IDN?，必须得到A/C/D/E之一及非空固件、序列号才进入主界面。只有TH2822系列名不能猜型号。
3. 自动读取参数上下文，并串行查询FETCh?。默认一轮完成后间隔500ms，可选250/333/500/667/1000ms；这不是仪表RATE，也不承诺同等实际刷新率。
4. 修改参数只发一次setter，等待后核对目标读回，再读取主副类型与TOL开关，成功后继续查询。0.3.9不再连带读取无关频率/电平/电路；主参数类型改变才全读上下文。不需要额外同步或RMT。
5. 仪表信息窗口提供重新读回按钮，可同步仪表按键修改的设置；主页面正常时隐藏故障恢复按钮；响应错误或超时使读数无效、停止采集并显示具体命令与返回值。用户可重新读回状态恢复，不自动重放setter。
6. 保持、语言和采集间隔是本地操作；统计来自仪表原生REC，没有本地清统计。仪表信息页只显示缓存型号、版本、序列号，不触发额外查询。USB断开销毁弹窗并返回连接页，重连重新握手。

0.3.9每轮FETCH前核对主副类型和TOL开关，防止AUTO变更时错标单位。频率、电平、电路等设置只在连接、对应设置读回、类型变化或手动同步时查询；这些缓存显示不能代替即时查询。TOL开启时逐轮查询仪表偏差，关闭时清空偏差。初次连接前可能已存在的主动测量帧仍在查询解析中有界丢弃，不能冒充IDN/参数响应。

## 身份信息

*IDN?只提供型号描述、固件版本、序列号；信息页仅展示这三个字段，完整响应可在通信记录或UART诊断查看。USB VID/PID来自枚举描述符，9600/8N1/无流控为实际配置。未提供的硬件版本不推测。设置区域是最近读回的缓存快照，不承诺弹窗期间实时变化。

## 验证边界

主机覆盖四机型连接→设置→读回→继续FETCH、错误停发、读回失败不重放、原有流分流及未知身份拒绝。原生LVGL预览覆盖离线、识别中、已连接、读数、信息、错误与断连返回。真实TH2822E的串口诊断保留在本地references，逐步记录观察范围；不推广为其他型号实测通过。

## E固件终止符对照

本项目在TH2822E VER4.5.2307上用CRLF发送时捕获过截断`VOLT? => [0.]`；仅改为手册允许的单LF后，55秒查询观察无该错误，用户确认在触摸屏改频率后自动继续且无橙色错误。因此发送统一采用LF，接收仍接受CR/LF/CRLF，严格拒绝不完整值。此为本台本固件证据，不把内部原因或其他型号稳定性当作已证实。

## 0.3.4交互补充

参数菜单显示当前值，重复选择当前值不派发设置。仅选择不同值才进入设置/读回流程。“主参数”不代表AUTO开关，“查询间隔”不代表FAST/SLOW，统计记录由原生REC提供。所有弹窗遮挡底层触摸，避免误触。此版本已构建与主机预览验证，尚未实屏验收。
