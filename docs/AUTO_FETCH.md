# 主动发送、身份握手与 RMT

## 证据范围

用户提供的《TH2822D/E Operation Manual V1.0.0》：

- 印刷81页：9600 baud、8 data bits、1 stop、无校验、无流控。
- 印刷82–84页：任何收到的远程命令会进入Remote，终止Auto Fetch。远程状态短按RMT回本地，本地短按RMT切换Auto Fetch；每完成一次测量自动发一次，LCD的RMT随发送闪烁。
- 印刷86–87与96页：ASCII、CR/LF/CRLF；FETCH返回AC三个字段（主、副、比较结果），DCR两个字段（主、比较结果）。
- 印刷90页：`*IDN?`返回型号、固件版本、序列号。印刷91页的`*GTL`仅说明回本地，不是开启Auto Fetch的命令。

用户后补的TH2822/A/C手册（与厂家原稿SHA256相同）印刷55–57页明确同样的RMT/Auto Fetch行为；58–67页给出SCPI，68–69页给出基础型号能力。0.3.2正式目标A/C/D/E四个型号默认主动接收；旧手册无后缀名称不作为第五个支持型号。仍无本项目仪表实测，参考CLI的D实测不扩大为全系列通过。

## 产品行为

1. 启动后等待原生USB设备；USB枚举、串口初始化、身份查询是不同状态，均不等于仪表已连接。
2. CP210x串口就绪后发送`*IDN?`。只有三个非空字段、可识别的TH2822A/C/D/E型号才建立仪表身份。只有TH2822系列名、未知后缀或不完整响应明确拒绝，不提供手动选型。
3. 一次读取主副参数、频率、电平和等效电路；DCR不读AC专用项。失败则锁定控制，显示错误。
4. 已识别系列型号默认等待Auto Fetch。这时不发FETCH、状态轮询、心跳或自动恢复命令。用户在仪表LCD的RMT常亮时短按退本地，本地再短按开始发送。
5. 主动接收有效测量帧即可更新读数。超过5秒无帧使读数失效并回到等待状态，保持已验证身份，不谎报USB拔出，也不后台发送命令。新帧到达可自然恢复。
6. 屏幕修改仪表设置或点击“同步设置”会进入远程、停止Auto Fetch；完成读回后再次引导RMT操作。保持、统计复位、界面语言均为本地操作，不打断流。
7. 用户可明确选择查询采集作为备用方式；250/500/1000ms是命令间采集间隔，不是仪表内部RATE。

不发送`*LLO`、`*GTL`、`*TRG`或未文档化的自动发送使能指令，不执行校准或仪表永久设置。

## 帧与上下文限制

当前按手册测量结果格式接收AC/DCR帧，支持十进制科学计数、连字符超量程、NR1有符号比较字段，以及参考D固件曾返回的N。Auto Fetch章节没有另给逐字节独立报文范例，因此实际流是否完全等于FETCH格式仍须仪表验证；遇到其他格式停止解析、显示并在UART记录原始行，不猜字段或伪造读数。

握手/设置查询时，已排队的合法测量帧会被分流丢弃，不能充当IDN或设置响应；总等待时间和可跳过行数有界。只有同一查询可以重试一次，设置不自动重放。

上报数据不带参数名或单位，软件无法发现L切C等保持相同字段数的面板改动。因此主动模式显示“同步设置”标签：测量时保持仪表参数不变；在仪表上改动后必须先点击“同步设置”，再恢复发送。AC/DCR字段数变化会被检测并停止，而不是套用旧单位。此限制不能通过后台查询解决，因为查询本身会停止流。

## 仪表到场验收

记录描述符、IDN全文与固件。先验证查询及状态读回，再按LCD状态操作RMT；保存至少20条真实Auto Fetch原始行，核对AC/DCR、OL、帧终止符和比较字段。确认主动接收时USB TX无周期命令；按RMT停流后身份保持但读数失效；恢复后自然更新。改设置应先停流、完成读回并提示重新开启。分别验证TH2822A/C/D/E，不能以一种型号推断另一种。
