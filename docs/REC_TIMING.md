# 原生统计、刷新间隔与设置时延（0.4.5）

## REC 通信与显示

本轮依据本台 TH2822E VER4.5.2307 的直连逐条测试重做 REC。原始返回及用户声响/LCD 观察见 [REC_DIRECT_TEST.md](REC_DIRECT_TEST.md)。0.4.3 的后台循环统计查询已撤除。这里不把本台实测扩大为全系列认证，也不使用本地统计补算。

| 界面 | 进入时发送一次 | 后台取数 | 显示 |
| --- | --- | --- | --- |
| 当前值（默认） | CALCulate:RECording:PRESent? | 本台 E：FETCh? | 实时主、副值；仪表 MAX AVG MIN 同亮 |
| 最大值 | CALCulate:RECording:MAXimum? | 不自动读统计 | 本次原生主参数读回、时间 |
| 平均值 | CALCulate:RECording:AVERage? | 不自动读统计 | 本次原生主参数读回、时间 |
| 最小值 | CALCulate:RECording:MINimum? | 不自动读统计 | 本次原生主参数读回、时间 |

- PRESent? 在本台返回 -----，但会选择记录当前显示；随后 FETCH 得到变化主副值。只对精确 E/VER4.5.2307 profile 使用这个已实测路径。进入当前值后保留直连测试的 1200 ms 间隔，再开始 FETCH；这是 REC 显示切换的保护等待，不回退普通参数设置的 100 ms 首次读回。
- 其他型号/固件暂按手册将 PRESent? 返回作为手动读回；不猜测 FETCH 在其 REC 子状态中的含义。界面相应显示“读回结果”和更新按钮，待真机验证后再放开实时路径。
- 原生最大/平均/最小仅显示主参数。实机副统计均返回零，未验证有效，不当作可信统计展示；当前页仍显示真实副参数。
- 三个统计页保留“读回结果”和启动后读回时间，不伪装持续更新。点击“更新读回”只发一次所选专用命令；AVG 绝不用 FETCH 代读，因为实机在 AVG 下 FETCH 曾返回 MAX。
- 选择统计项或重复更新会触发仪表提示音。后台只进行普通参数/状态查询，不自动轮换统计项，也不反复读取同项。重复点击已选页签不发送选择命令。
- 所有 REC 显示选择命令禁止自动重试。超时/格式错误清空读数、标记未知、停止采集并显示错误；需用户重新读回或重连，不以重复命令掩盖失败。
- 新开 REC 或接入已开 REC 的仪表，默认选择当前显示一次；这可能提示一声。不会后台 OFF→ON，不清除原生累计记录。重复开启已开启 REC 不再发 ON。
- 检测到 REC 开启自动打开统计页；关闭/重开页不停止记录，也不重复选择显示。只有停止记录发送 OFF。OFF/断开后清除旧读回；查看统计快照时普通主界面读数留空，不混淆为实时测量。
- 开启 REC 后需先停止再改测量设置或进入比较，防止统计条件混合；外部同时开 TOL/REC 时仍可停止 REC。没有使用清零、校准或永久设置命令。
- 读回时间是启动后的单调运行时间，不是日期；无本地累计、样本数或副参数替代算法。

命令依据为 D/E V1.0.0 手册印刷页 95–96 及 A/C 通信章节。官方 REC 默认 MAX AVG MIN 同亮表示当前记录显示，MAX/AVG/MIN 单亮是所查看的统计项，不是四种互斥的统计算法。

## 刷新与设置

默认一轮完成后等待 500 ms，可选 250 / 333 / 500 / 667 / 1000 ms；实际周期还包括仪表响应，不能等同 FAST/SLOW。

设置队列优先于下一轮采集。设置结束立即安排新查询；不打断已在途查询，以免响应混叠。E VER4.5.2307 首次等 100 ms 后读回，匹配即继续；不一致最多追加三次同命令读回，等待 100 / 200 / 400 ms。设置只发一次，特别是 TOL ON 不重发。异常超时仍执行有界重试和迟到响应隔离，不承诺固定低时延。

本机 0.4.1 的真实触摸日志：
- 频率设置：排队 284 ms、执行 268 ms、总计 552 ms。
- 副参数设置：排队 0 ms、执行 337 ms。
两次均 ready=1 且 error 为空，已消除固定 1.2 秒空等。不是所有参数/速度/固件的全面实机验收。D VER4.5.2307 保留 800 ms，其他未实测型号/固件保留 1200 ms。

## 顶部布局与指示

型号保持白色，小圆点按实际文字宽度紧随其后；设置 TX 红闪、查询 TX 蓝闪、空闲暗色，短脉冲保留约 150 ms，红色优先。RX/错误/本地动作不触发设置红灯；TX 不代表仪表已执行成功。

“常规测量 / 容差比较”作为一组在 800 像素宽度中居中。“设备信息”恢复通用按钮样式，按文字宽度加内边距，右侧对齐 24 像素边距。信息只显示型号、版本、序列号；通信记录另页查看。


## 断联与底部操作

物理断联后退出测量主界面，在连接页上显示错误浮层；已识别仪表的协议/读回失败也显示浮层。“重新读回”在浮层内：物理连接存在时重新读状态，已断开时重建连接；不会自动开启 TOL、重新取基准或重启 REC。成功恢复后浮层自动关闭。0.4.5 按用户要求移除关闭按钮；浮层只能在恢复成功后自动收起，重新读回集中在浮层内。初次未接仪表仍显示原连接页，不弹错误。

常规测量第三行为刷新 / 统计记录 / 保持；容差比较第三行为刷新 / 容差设置 / 保持，均为240 px。主界面移除重新取基准，仅保留容差设置浮层内入口。

## 验证与实机边界

五组 CTest（含 ASan/UBSan）、中英文真实 LVGL 交互通过。新增覆盖选择仅一次、AVG 不被 FETCH 覆盖、快照后台不变、手动更新、超时不重试、未知固件保守路径、关闭重开不重置、外部 REC 开关、错误浮层恢复/再次断联及底部按钮尺寸。原 TOL、通信日志拖动、语言和顶部布局回归保留。

截图带 TEST INPUT / NO INSTRUMENT，不能当作真实仪表数据。目标构建和实际烧录信息见 [VALIDATION.md](VALIDATION.md)。原生统计数值准确性仍需稳定元件对照；之前开路测试只能确认协议与显示行为。A/C/D 及其他 E 固件未进行本轮硬件联调。

0.4.5 统计页不再展示 MAX/AVG/MIN 指示灯含义说明；当前页保留主副读数，统计快照保留读回时间。原生通信逻辑未变。
## 0.4.9：容差超限提示及重绘优化

比较页使用原生 CALC:TOL:VALU? 返回的偏差百分比与已读回的 1/5/10/20% 档位显示结果：绝对偏差 <= 档位为绿色“容差内”，超过为红色“超出容差”，同时改变右卡边框与背景。不重新计算偏差/基准，不猜测 FETCH BIN 码（本台 TOL 开启时仍多次返回 N）。保持、无效基准、无效/非有限偏差、超量程、未选档位、通信错误和等待设置分别提示，不伪装合格。正负边界及四档、NaN/零基准、保持状态已用主机测试覆盖；中英文真实 LVGL 场景及原有完整回归通过。

从本地锁定 LVGL 源码确认每次 set_local_style_prop 都调用 refresh_style，故通信圆点现仅颜色实际变化时设置样式，避免相同颜色造成重复整屏重绘。仍使用既有稳定 RGB full_refresh 双缓冲时序。

0.4.8 真实用户点击证据保存在 references/boot-v0.4.8.log：普通频率排队119ms/执行268ms/首样本820ms；电平排队451ms/执行292ms/首样本1327ms；副参数一次排队0ms/执行412ms/首样本577ms。执行后立即 FETCH，日志确认已省去重复元数据查询。另一次 FREQ 120 的100ms后首次 FREQ?没有回应，经1800ms超时和1200ms隔离后重试成功，执行3470ms、首样本3666ms。这是仍存在的慢响应边界，没有通过缩短迟到响应隔离或重发设置冒险掩盖。FETCH 在120Hz现场也有约488–584ms等待，不能只凭软件提速承诺固定总延迟。

本轮 TOL ON/OFF、频率、电平和副参数操作由用户触摸触发；监控脚本只发送板内 trace/state。未自动改变校准/永久设置或重新取基准。0.4.8监控已结束、串口关闭。
