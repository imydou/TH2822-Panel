## 结论与边界

在本台 E VER4.5.2307、当前 C/NULL 测量条件下，VOLT 设置本身足以引起原生偏差更新停滞，即便 STAT? 返回 ON。串并联单独改变未复现；不能由电平之后仍停滞的现场推断电路设置也有同样问题。也不能把本轮未复现扩大为所有模式下电路都无问题。

重复档位、改变档位、GTL 和重复 ON 均未恢复；OFF→ON 恢复但会覆盖参考。没有发现保留原基准的已验证远程恢复方法。禁止把未经验证的档位重发或自动 OFF→ON 当作透明修复，也不能仅因为偏差连续相等就自动判定停滞。

安全操作顺序：先设置电平等测量条件，再接参考元件、明确开启 TOL 捕获基准。实际使用中需要改变电平时，应明确结束旧比较，再由用户确认新基准；不要后台拿待测元件重取参考。这是操作建议，本轮未改变触控屏行为，固件仍为 0.3.9。

收尾恢复原始 C / NULL / PAL / 1kHz / 0.6V、TOL OFF；最后发送 GTL 并关闭串口，后续无查询再次进入远程。开路测试参考已随 TOL OFF 清除。
