# 常规测量与容差比较（0.4.3）

## 模式切换

主界面顶部使用“常规测量 / 容差比较”，以仪表 CALC:TOL:STAT? 的实际结果显示选中状态，不以点击动作预先切换。

- 常规测量切至容差比较：打开取基准确认窗口，当前主读数随测量持续刷新；取消不发设置命令。接入参考元件、待读数稳定后明确点击“以当前值为基准”，原生 ON 成功并返回参考后进入比较。无效、零值或保持中禁止确认。
- 容差比较切至常规测量：发送原生 OFF 并核对结果。失败显示错误、锁定设置，不错误宣布常规测量。
- 仪表连接时已开启 TOL：直接使用实际模式、参考和档位，不重新捕获。
- 重新取基准仍需确认，以 OFF→ON 实现并恢复已选档位；绝不作为后台恢复策略。

## 显示与参数保护

常规测量显示主副读数，统计记录按钮进入仪表原生 REC。容差比较显示主读数、带符号的原生偏差百分比、基准和容差范围；不把未经验证的 FETCH 结果码解释为合格/不合格。

比较期间主参数、副参数、频率、电平显示原值并带锁；点击提示先切换到常规测量，不打开参数列表或发设置命令。串并联、容差档位和本地刷新/保持仍可用。正常模式下恢复型号能力门控。

命令执行层对上述四种参数的每次有效设置先读真实 TOL 状态；即使是排队动作或仪表物理按键刚开启 TOL，也阻止受保护设置。未确认状态时不继续设置。这是用户选择的明确模式策略，不是声称仪表面板自身不允许这些操作。

偏差使用 CALC:TOL:VALU?，不在开发板计算。电平命令导致停滞的 E VER4.5.2307 实测见 TOL_DIRECT_TEST.md；本版通过禁止比较中的电平设置避开该已知触发条件，并未修复仪表内部固件。

## 仪表信息与通信记录

右上角设备信息只显示型号、版本、序列号。提供重新读回、语言、通信记录入口；不再放冗长的传输配置和原始身份说明。移除主界面的“触摸控制”“自动采集”等说明。

通信记录为独立页面，保留最近80条协议收发/错误记录：
- RAM固定环形缓冲，不写Flash，重启后清空。
- 时间为开发板启动后的时分秒毫秒；TX发送请求、RX收到的完整行、ERR错误。TX记录不代表仪表已经执行成功。
- 默认跟随最新内容；拖动向上查看或点击暂停跟随时，冻结当前显示快照，采集及内存记录继续。
- 回到最新恢复跟随；清空显示只设置显示起点，不发仪表命令。
- 页面打开/返回不会设置仪表模式、重取基准或停止测量。
- 未连接页面也可查看最近通信记录。断开连接时回到未连接界面，可重新打开记录。
- 每条最多191个可打印ASCII字节；控制字符和界面颜色标记字符转义为问号，原始完整UART诊断仍按需启用。

本地保持只冻结主界面读数；原生 REC 仍由仪表继续记录，统计页显示最新查询结果。不会让仪表进入 HOLD。

## 验证边界

主机协议/调度/能力及原生TOL回归、语言检查、中英原生LVGL预览通过。覆盖：ON确认取消、确认窗口实时数值、受保护按钮无设置、后台状态变化仍锁定、失败OFF不误切模式、串并联/档位可用、日志拖动暂停/恢复/清空不发命令、断线返回等待界面、固定缓冲保留顺序及截断。

模拟截图带 TEST INPUT / NO INSTRUMENT 标签，不属于真实仪表数据。A/C/D功能按文档和模拟覆盖，未进行这些机型的实机认证。
