# 官方上位机功能与触控交互借鉴

2026-10-07。依据用户提供的官方3.0.1应用资源、已提取的主界面与数据常量，以及当前触控固件源码。没有运行Windows程序，因此下述内容是可确认的功能结构和触控设计建议，不冒充桌面软件运行录像、完整菜单复原或串口时序实测。二进制证据见[软件分析](SOFTWARE_ANALYSIS.md)。

## 功能和流程对照

| 官方软件资源可确认的功能 | 对触控面板的意义 | 实现安排 |
|---|---|---|
| Primary、Secondary、Frequency、Measurement，Series/Parallel选项 | 测量上下文应随读数可见，改变参数无需进入多级设置页 | 保留主界面六个快捷入口；“模式”改为“主参数”，避免与AUTO混淆 |
| 模型相关频率列表、Disabled/Disabled Items属性 | 可选能力需要明确反馈；从资源推断有按型号调整选项的逻辑，未动态验证全部分支 | 继续使用经手册核对的A/C/D/E能力门控；菜单不支持项显示文字而非仅变灰 |
| Start、Stop、Record Data、Clear Data分别存在 | 采集、显示保持、记录、清除是不同动作，名称应指出作用对象；具体桌面按钮时序未动态确认 | 当前“保持”为本地显示/统计保持，仍查询仪表；“重置”改为“清统计”，不是清记录或仪表复位 |
| 数据列Primary/Secondary/Date-Time、Text/Excel保存与成功/失败提示 | 记录应该保存当时读数和测量上下文，形成可追溯批次 | 后续独立记录页：启停记录、样本数、参数摘要；修改测试参数分批；CSV导出另行实现，不宣称已有存储功能 |
| Tolerance、Relative、PASS/FAIL、1/5/10/20% | 适合批量筛选，与日常读数是不同任务 | 后续比较页；若做本地相对值/容差必须明确“本地计算”、基准单位及有效性。不能直接发包内BK型号相关命令 |
| Version、*IDN?、连接失败和参数失败消息 | 身份、当前配置及错误应可追查 | 保留独立连接页与仪表信息页；后续可增加可展开的错误详情和设置过程记录 |
| 未找到AUTO或FAST/SLOW入口 | 不足以解锁原生功能 | 不新增假选项，不用查询间隔冒充测量速度，也不添加替代AUTO算法 |

建议的触控结构为“测量主屏 → 按需打开参数卡片”，记录、比较各自独立。800×480主屏优先给大号主副读数和常用参数，避免把桌面的数据表、菜单栏、全部统计功能同时压入主屏。没有证据表明官方软件一定有曲线图，本项目的趋势图只能作为新设计建议。

## 本轮已实现：0.3.4

1. 参数弹窗改为两列294×88大触摸区域，五个频率选项能同时显示；当前值有文字、底色和边框标记。
2. 点击当前值直接关闭，不向操作队列派发重复设置。尤其是重写主参数/频率可能影响原生AUTO，避免这种无必要写入；这不等于实现了AUTO远程控制。不同值仍走原有一次设置、读回确认、自动继续采集流程。
3. 参数、语言、操作说明和仪表信息弹窗统一使用全屏输入遮罩。弹窗之外的点击不能触发背后的保持/清统计等按钮；关闭使用显式关闭按钮。
4. “模式”改成“主参数”，“重置”改成“清统计”，“采集”改成“查询间隔”；间隔菜单明确不是仪表FAST/SLOW。
5. 原“主参数或AUTO不支持，请到仪表选模式”错误提示改成准确的“主参数读回无法识别”。已实证AUTO亮时也可返回C，不能由异常返回就暗示必须到仪表退出AUTO。

本轮仅UI、语言资源及相关预览验证变化。未改USB传输、SCPI命令集、测量调度或稳定显示配置。协议核心仍只执行已实现的参数命令。

## 验证与限制

- 原生LVGL预览（中/英）：未连接、身份识别、主屏、频率菜单、信息、说明、错误、断连返回；均标识TEST INPUT / NO INSTRUMENT，不是真机数据。
- 用指针按下/释放模拟点击遮罩外的底层保持按钮位置，确认没有动作；不是仅对函数做调用断言。
- 主参数、副参数、频率、电平、串并联、查询间隔六类当前值选择均不派发动作；改到不同频率只派发一个动作，并经测试仪表读回。
- 既有主机协议/调度/能力及语言测试3/3通过，locale键与占位符检查通过，ESP32-S3目标构建通过。
- main/board.c与sdkconfig哈希保持已验收基线；没有再次调整PCLK、RGB帧缓冲或任务绑核。
- 未刷入开发板；新增半透明遮罩和双列菜单的实屏显示、触摸边界、连续开关菜单仍待真机验收。不能仅凭桌面预览承诺没有闪烁。

后续优先顺序：本轮日常测量改进实屏验收 → 本地记录/大字号统计 → 有明确需求时做批量比较。导出格式、记录容量、断电保存及比较基准管理需要单独定义，不随本次UI优化隐式加入。
